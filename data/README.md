# Data Folder Structure

data/
├── raw/ # Original datasets (not pushed to GitHub)
├── processed/ # Cleaned + normalized audio
├── combined/ # Speech + non-speech mixed audio
├── speech/ # Individual speech files (post-cleaning)
└── nonspeech/ # Individual non-speech (ambient/environmental)


> ⚠️ Large `.wav` files are excluded from GitHub for storage efficiency.  
> Team members can access the full dataset via the shared Google Drive link.
